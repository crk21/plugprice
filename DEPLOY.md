# Deploying PlugPrice
`site/` is a fully static folder (relative links, no server code). ~16.6k files, ~36 MB apparent size.

Daily: `./run.sh` (fetch.py -> data/snapshots + data/history diff; build.py -> site/). Set `AFDC_API_KEY` (free at developer.nlr.gov) — DEMO_KEY is rate-limited.

## Options (all free tiers)
- **Cloudflare Pages**: limit 20,000 files/deploy (we're at ~16.6k — watch growth). `npx wrangler pages deploy site --project-name plugprice`.
- **GitHub Pages**: push `site/` via a GitHub Action that runs `run.sh` on a `schedule:` cron and deploys with `actions/deploy-pages`. Commit `data/snapshots` (or only `data/history` + latest snapshot, ~9 MB/day otherwise) so diffs persist between runs.
- **Netlify**: `netlify deploy --dir=site --prod`; scheduled rebuild via build hook.
